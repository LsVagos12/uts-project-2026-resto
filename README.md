# 🍽️ YAP Foodlab - Project UTS Android 2026

Aplikasi profil dan eksplorasi menu restoran modern berbasis Android menggunakan **Jetpack Compose** dan arsitektur *State Management* terintegrasi dengan **SharedPreferences** untuk penyimpanan data lokal yang persisten.

Aplikasi ini menerapkan aspek **Vibe Coding** penuh dengan menghadirkan antarmuka (UI/UX) yang padat, responsif, dinamis, serta kaya akan animasi halus layaknya aplikasi *food delivery* komersial.

---

## ✨ Fitur Unggulan & Aspek Kreativitas (Vibe Coding)
1. **Dynamic Dual Theme Engine (Force Dark/Light Mode):** Sistem pergantian tema instan melalui sakelar di Beranda yang memaksa palet warna berubah secara kontras dan persisten disimpan di SharedPreferences.
2. **Realtime Live Search Filter:** Kolom pencarian di halaman menu yang menyaring hidangan secara langsung (*real-time*) saat pengguna mengetik.
3. **Interactive Cart Badge Tracker:** Simulasi keranjang belanja yang melacak jumlah item dengan indikator angka (*badge notification*) pada ikon menu bawah.
4. **Interactive Star Rating & Favorites System (❤️):** Pengguna dapat memberikan rating bintang 1-5 yang menyala interaktif serta menandai hidangan tersuka dengan tombol hati.
5. **Native Android Share Intent:** Tombol aksi berbagi di halaman detail yang beneran memanggil dialog sistem bawaan OS Android untuk menyebarkan informasi menu.
6. **Polished Bottom Navigation Bar:** Navigasi global bawah terstruktur yang rapi dilengkapi dengan transisi antar halaman (*fade & slide animation*) yang super mulus.
